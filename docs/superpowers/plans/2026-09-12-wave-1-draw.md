# Agent Flow Builder, Wave 1 (Draw) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Draw wave of the Agent Flow Builder: a Next.js app where Nick draws agent workflows on a React Flow canvas with 13 node kinds, saves them as committed JSON plus browser drafts, and shares them as locked view-mode pages on an unlisted Vercel preview.

**Architecture:** A single Next.js 16 App Router app. Committed flows in `flows/*.json` are validated by a zod schema and statically built into `/flow/[slug]`; a zustand store (with zundo undo history) holds the live React Flow graph and persists drafts to localStorage through one subscriber. Four Flow Kit primitives are vendored from `flow-kit-worktree@b414ac9` and extended with an optional port suffix; a node catalog drives the palette, the inspector forms, the ports, and the renderers. `while` is a React Flow group node containing its body, so the graph is always acyclic.

**Tech Stack:** TypeScript · Next.js 16.2.9 · React 19.2.4 · Tailwind v4 · shadcn (style `base-nova`, neutral, Base UI) · `@xyflow/react` ^12.11 · zustand 5 + zundo · zod 4 · lucide-react · Vitest 4 + Testing Library (jsdom) · Playwright 1.60 (Chromium + WebKit) · pnpm · GitHub Actions · Vercel.

**Spec:** `docs/superpowers/specs/2026-09-12-agent-flow-builder-design.md` (read it first; this plan argues from it).

### `lib/flow-schema.ts`

```ts
export const NODE_KINDS = ["start", "agent", "classify", "end", "note", "file-search", "guardrails", "mcp", "if-else", "while", "user-approval", "transform", "set-state"] as const;
export type NodeKind = (typeof NODE_KINDS)[number];
export type NodeGroup = "core" | "tools" | "logic" | "data";
export type FlowSource = "manual" | "claude-code" | "openclaw";

type Base = { label: string; description?: string };
export type StartData = Base & { trigger: "manual" | "schedule" | "webhook" | "event"; triggerDetail?: string };
export type AgentData = Base & { instructions: string; model?: string; tools?: string[] };
export type ClassifyData = Base & { categories: string[] };            // min 1
export type EndData = Base & { outputLabel?: string };
export type NoteData = Base & { text: string; color: "yellow" | "blue" | "green" | "pink" };
export type FileSearchData = Base & { store: string; topK?: number };
export type GuardrailsData = Base & { checks: string[] };
export type McpData = Base & { server: string; tools?: string[] };
export type IfElseData = Base & { conditions: { label: string; expression: string }[] };  // min 1
export type WhileData = Base & { condition: string; maxIterations?: number };
export type UserApprovalData = Base & { prompt: string };
export type TransformData = Base & { expression: string };
export type SetStateData = Base & { assignments: { key: string; value: string }[] };

export type KindData = {
  start: StartData; agent: AgentData; classify: ClassifyData; end: EndData; note: NoteData;
  "file-search": FileSearchData; guardrails: GuardrailsData; mcp: McpData; "if-else": IfElseData;
  while: WhileData; "user-approval": UserApprovalData; transform: TransformData; "set-state": SetStateData;
};
export type AnyKindData = KindData[NodeKind];

export type FlowNode<K extends NodeKind = NodeKind> = {
  id: string; kind: K; position: { x: number; y: number }; parentId?: string; width?: number; height?: number; data: KindData[K];
};
export type FlowEdge = { id: string; source: string; target: string; sourceHandle: string; targetHandle: string; label?: string };
export type FlowViewport = { x: number; y: number; zoom: number };
export type Flow = {
  schemaVersion: 1; id: string; name: string; description?: string; source: FlowSource; sourceRef?: string;
  createdAt: string; updatedAt: string; nodes: FlowNode[]; edges: FlowEdge[]; viewport?: FlowViewport;
};
export type FlowMeta = Pick<Flow, "id" | "name" | "description" | "source" | "sourceRef" | "createdAt" | "updatedAt">;

export const flowSchema: z.ZodType<Flow>;
export type ParseResult = { ok: true; flow: Flow } | { ok: false; errors: string[] };  // errors: "nodes[3].data.categories: expected at least 1 item"
export function parseFlow(json: unknown): ParseResult;      // runs migrateFlow first
export function migrateFlow(json: unknown): unknown;        // v1 passthrough; throws Error("unsupported schemaVersion X") otherwise
export function isSlug(s: string): boolean;                 // /^[a-z0-9][a-z0-9-]*$/
export function newDraftFlow(now?: Date): Flow;             // id `draft-` + 6 lowercase alphanumerics, name "Untitled flow", source "manual", one start node at {x:0,y:0}
```

Schema rules: `parentId` may only reference a node whose kind is `while` (refinement); every edge's `source`/`target` must exist (refinement); `sourceHandle`/`targetHandle` must parse with `parseHandleId` and carry the edge's `source`/`target` as `nodeId` (refinement); `id` must satisfy `isSlug`. Unknown `kind` fails with `nodes[i].kind: unknown kind "x"`.

## Test conventions

- `vitest.config.ts`: `@vitejs/plugin-react`, `environment: "jsdom"`, `globals: true`, `setupFiles: ["./vitest.setup.ts"]`, `include: ["**/*.test.{ts,tsx}"]`, `exclude: ["e2e/**", "node_modules/**", ".next/**"]`, `css: false`, alias `@` → repo root.
- `vitest.setup.ts`: imports `@testing-library/jest-dom/vitest`; stubs `ResizeObserver`, `HTMLElement.prototype.scrollIntoView`, `hasPointerCapture`, `setPointerCapture`, `releasePointerCapture`, `window.matchMedia` exactly as the Flow Kit app does; adds a `localStorage` reset in `beforeEach`.
- Components that render handles or the canvas are wrapped in `<ReactFlowProvider>`; store-backed components are wrapped in `<FlowStoreProvider store={createFlowStore(fixtureFlow)}>`. A shared `lib/test-fixtures.ts` exports `fixtureFlow()` (start → agent → end, one note) and `renderWithStore(ui, store?)`.
- Canvas tests assert on DOM (`[data-id="..."]`, `[data-handleid="..."]`, `data-slot`), never on visibility or pixel positions. Interaction across the real canvas is Playwright's job.
- Store tests use `createFlowStore(fixtureFlow())` and call actions through `store.getState()`; undo through `store.temporal.getState().undo()`.
- Playwright: `playwright.config.ts` with projects `chromium` and `webkit`, `testDir: "./e2e"`, `baseURL: "http://127.0.0.1:3100"`, `webServer: { command: "pnpm start --port 3100", url, reuseExistingServer: !process.env.CI }`. CI runs `pnpm build` before e2e.
- Commands: `pnpm test` (vitest run), `pnpm test -- <path>` for one file, `pnpm e2e` (playwright test), `pnpm lint`, `pnpm typecheck` (tsc --noEmit), `pnpm check:tokens`, `pnpm build`.
